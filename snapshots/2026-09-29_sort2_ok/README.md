## 1 つのときから変えたこと（効いたもの）

- **探し方**：手の届く帯（土台の軸から 14〜23 cm、正面から ±45°）を 2 列 × 4 か所で一巡して一覧を作り、色で選んでから詰める。
  移動中にちらっと写った物は記録し、一巡で見つからなければ戻って見直す。向きを変えても画像の同じ所に写る物は外す。
- **1 つ置いたら残りの色だけを探す**（卓上の他の青い物に色を固定されないように）。一巡して無ければ終わる。
- **色**：青は彩度 0.8・明るさ 0.2 以上（卓の水色のシートは彩度 0.3〜0.7）。緑は彩度 0.45・明るさ 0.06 以上（白い紙の上で暗く写る）。
- **挟めた判定**：145 で閉じ、読み戻しが 120〜141 なら挟んでいる（空 144〜145、3 cm を挟むと指がたわんで 139）。
  閉じた直後と持ち上げた後の 2 回確かめる。以前の 125〜134 では挟めているのに外し、自分で指を開いて落としていた。
- **腕はゆっくり**（探索 2.5 s、振り付けは 1.7 倍）、指先は卓上 1.2 cm。
- **板の HTTP**：係からの問い合わせを 1 本の列にし、カメラは 0.8 s 間隔で係だけが取り込む。窓は係から画像を読む。
- **模型**：窓の刻みは Web Worker（Chrome が隠れた窓のタイマーを間引くため）。
